# Proyek 82: Text Case Converter (Pengubah Format Case Teks)

Proyek ini adalah aplikasi web interaktif untuk mengonversi format kapitalisasi teks (*UPPERCASE*, *lowercase*, *Title Case*, *camelCase*, dll.) dan menghitung statistik teks (*karakter*, *kata*, *kalimat*, *paragraf*) secara *real-time*. Dibuat menggunakan **HTML5, CSS3, dan Vanilla JavaScript**, sangat cocok untuk pembelajaran manipulasi *string* dan ekspresi reguler (*RegEx*) bagi pemula/siswa SMK.
